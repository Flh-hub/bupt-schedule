## 2. 本轮时间线：用户提的 9 个问题 → 各自根因

| 5 | 「还是不行」 | 上一轮只改了阈值，没碰真正的 `.tt-scroll` | 见 #3 |
| 6 | 「加个 😊 表情」 | — | 彩蛋文案末尾加 😊（课表卡片 + 小组件） |
| 7 | 「活动时间超过了最后一节课的时间后面就不显示了」 | `timeToRowUnits` 对晚于最后一节的时间**一律返回节数**（21:00 和 23:00 算成同一行），`timePlacement` 又把 rowIndex 夹进 `rows-1` | 改成按最后一节的「分钟→行」比例外推；`timePlacement` 不再 clamp；网格按需延长 |
| 8 | 「第一次划拉长格子」→「线不会往下走，删活动时底下格子应该删」 | ① 起点在最后一节**之内**但高度溢出时，`grid-row` 没越界，浏览器不会补隐式行，块被裁；② 红线 `getNowMarker` 晚于最后一节时直接返回「最后一行 + fraction 1」，钉死不动 | ① 网格按 `bottomUnits` 补延长行（左侧带时间刻度）；② `getNowMarker(state, now, maxRow)` 新增封顶参数，UI 传入网格实际行数 |

## 4. 几条必须记住的实现约定

1. **「今天课上完了」不能看"有没有下一节"**：`getNextClass` 只找还没**开始**的课，
   9:00–9:45 的课在 9:20 时它也返回 null。统一用「最晚结束时间是否已过」。
2. **跨午夜（end < start）一律算没完**：真正结束是在第二天。
3. **默认节次表是 11 节不是 14**（最后一节 20:10–20:55）；用户自己改成了 14 节。写死 14 会错。
4. **延长行不编造节次号**：课程表就 N 节，第 N+1 节不存在，只给起止时间。
5. **网格延长行同时决定红线能走到哪**：`getNowMarker` 的 `maxRow = periods.length + needRows`。
6. **删活动后延长行必须一起消失** —— 现在是靠"每次渲染重新扫 `isEvent`"保证的，别再加缓存。

## 5. ⚠️ 踩过的坑（务必继承）

### 5.1 真机测试三连错（前几轮"修不对"全是它造成的）

1. `adb shell input` 用**物理像素**（本机 1272×2772），CSS 视口只有 **363×735**（dpr 3.5）。
   一直拿 CSS 坐标传过去 → 全打在页面顶部。正确做法：`CSS 坐标 × devicePixelRatio`。
2. App 必须在**前台**（`dumpsys window | grep mCurrentFocus`）。否则事件打在桌面，
   但 WebView 还活着能 eval，读数全是 0 —— 会得出"完全不滚"的错误结论。
3. 课表滚动发生在 `.tt-scroll` 容器里，读 `window.scrollY` 恒为 0 是**正常**的。
   先看 `document.querySelector('.tt-scroll').scrollHeight / clientHeight`。

补充：CDP 的 `Input.dispatchTouchEvent`「按下后立即快速移动」不触发滚动，
判断"能不能滚"要用 `adb shell input motionevent` 分步派发（走系统输入通道，更真实）。

### 5.2 ColorOS `adb install` 报 `Failure [-99]`

拦的是 incremental/streamed 路径。`adb install -r --no-incremental` 直接 Success；
`push + pm install` 同样是 -99。

### 5.3 删文件只写具体文件名逐个删

我用 glob 配白名单，误删过项目原有的 7 个探针
（`.probe-capture / -holiday / -makeup-prompt / -overlay-scroll / -picker / -ui / -update .mjs`）。
回收站里只剩 `$I` 索引、没有 `$R` 内容，**找不回来**。它们不在 `tests/` 的 474 条里，不影响 App，但确实是损失。

### 5.4 别在真机上随手截整屏

截整屏时前台不是本应用，拍到过用户的私人聊天内容。截图已删、全程未转述。
规矩：截图前先确认前台；优先用 CDP `Runtime.evaluate` 读 DOM 文本做断言；
必须截图就用 `Page.captureScreenshot` 的 `clip` 只截被测区域，用完即删。

### 5.5 验证长按拖拽会真改课表

我误把「程序设计与编程方法」挪到了周二第 5-6 节（已手动回滚，`adjustments` 归零）。
规矩：**先备份 `localStorage['bupt_schedule_v1']` 到文件，验完整体写回**（别逐条删，漏一条就是假活动）。

### 5.6 改完先 `node --check`

本轮重排代码时留过重复的 `let maxBottom` 声明 —— 直接白屏。

### 5.7 打包必须 aapt v1

Windows 版 aapt2 的 `-A assets` 会产出反斜杠条目名 → 手机上白屏。
`compileSdk = 36`，**`targetSdk` 保持 33**（35+ 强制 edge-to-edge，会动全屏 WebView 版面）。
