# 各品牌 Android「自启动 / 后台活动 / 电池」设置路径

> 适用版本：1.47.0 起（App 内「提醒 → 后台保活设置」是同内容的可点版本，会自动高亮你的机型）
> 目标：让**上课闹钟准点响**、**后台更新课表能跑完**。做完不影响课表本身，不做也能正常用。

---

## 0. 先说清楚：为什么需要这些设置

Android 保后台这件事有 **四层** 拦截，越往下越"厂商自创"：

| 层 | 机制 | 对本应用的影响 |
|---|---|---|
| 1 | 通知权限（Android 13+ POST_NOTIFICATIONS） | 没给 → 通知根本不出现（闹钟有跑，但你看不到） |
| 2 | Doze / App Standby（Android 原生） | 长期不用会进"待机分组"，唤醒窗口被拉长 → 闹钟可能晚几分钟到几十分钟 |
| 3 | 电池优化白名单（`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`） | 没加 → 上面第 2 层照旧生效 |
| 4 | **厂商自启动 / 后台活动 / 深度休眠**（MIUI、ColorOS、OriginOS、鸿蒙、One UI…） | 没放开 → 进程被清、闹钟被撤销、后台抓取半途中断。**第 3 层管不到这一层** |

本应用的工作方式决定了它需要什么：

- 提醒靠 **AlarmManager 系统闹钟**（`setExactAndAllowWhileIdle`），不需要常驻进程；
- 后台更新靠**一次短时抓取**（几秒到几十秒），不需要长期后台网络；
- **没有前台服务、没有常驻通知**，所以不需要（也不应该）关掉系统省电。

⇒ 只要放行「通知 + 电池优化 + 自启动/后台活动」，就够了。

---

## 1. 所有系统都要做的三件事

1. **通知权限**：允许通知，并打开「上课提醒」这个通知类别（Android 8+ 有渠道概念，只给总开关不给渠道照样静音）。
2. **电池优化**：本应用设为「不优化 / 不受限制 / 允许后台高耗电」。
3. **自启动 + 后台活动**：允许（关联启动一般**不需要**给，给了只会多耗电）。

App 内路径：**提醒 → 后台保活设置**，页面上有「打开本应用设置」「电池优化」两个按钮，直接跳到系统页面。

## 2. 小米 / 红米 / POCO（MIUI、HyperOS）

主要入口
- `设置 → 应用设置 → 应用管理 → 北邮课程表`
- `设置 → 电池 → 应用智能省电`（部分版本叫「省电策略」）

步骤
1. `设置 → 应用设置 → 应用管理 → 北邮课程表 → 通知管理`：允许通知，打开「上课提醒」类别。
2. 同一页 → **省电策略** → 选「**无限制**」。
3. `设置 → 应用设置 → 授权管理 → 自启动管理` → 打开本应用。
4. `设置 → 电池 → 右上角齿轮 → 应用智能省电`：确认本应用不是「智能限制」。
5. 最近任务 → 长按本应用卡片 → 点**锁定**（避免一键清理把它带走）。

影响
- 默认「智能限制」会把不常用应用的闹钟合并到系统唤醒窗口，**课前提醒可能晚十几分钟**；
- 后台更新若在「智能限制」下被掐断，会表现为"进度条走到一半停了，数据没变"；
- 设为「无限制」+ 自启动后，闹钟与短时后台都能正常完成。

注意
- 「神隐模式」是 MIUI 特有的后台联网限制，若开了，请把本应用加入「允许后台联网」名单。
- 不建议关「MIUI 优化」——会影响系统稳定性，且对闹钟没有帮助。

---

## 3. OPPO / 一加 / realme（ColorOS、OxygenOS）

主要入口
- `设置 → 应用 → 自启动和关联启动`（旧版：`自启动管理`）
- `设置 → 电池 → 应用耗电详情`

步骤
1. `设置 → 通知与状态栏 → 应用通知管理 → 北邮课程表`：允许通知，关闭「智能静默」。
2. `设置 → 应用 → 自启动和关联启动` → 打开本应用的**自启动**（关联启动可关）。
3. `设置 → 电池 → 应用耗电详情 → 北邮课程表` → **允许后台活动**。
4. `设置 → 电池 → 更多设置` → 关闭「**睡眠待机优化**」。
5. 长按桌面图标 → 应用信息 → 电池 → 「允许后台运行」。

影响
- 「睡眠待机优化」会在夜间收紧后台，通知被压到下一唤醒窗口 → **早八的课最容易迟到提醒**；
- 不给「允许后台活动」时，后台更新常在 10 秒内被中断；
- ColorOS 的「关联启动」只影响应用之间互相拉起，本应用不需要，保持关闭更省电。

注意
- 别开「超级省电模式」，它会一刀切清理几乎所有第三方后台。

---

## 4. vivo / iQOO（OriginOS、Funtouch）

主要入口
- `设置 → 电池 → 后台耗电管理`（旧版：`后台高耗电`）
- `设置 → 应用与权限 → 权限管理 → 自启动`

步骤
1. `设置 → 通知与状态栏 → 应用通知管理 → 北邮课程表`：允许通知，打开「锁屏通知」。
2. `设置 → 电池 → 后台耗电管理` → 本应用选「**允许后台高耗电**」。
3. `设置 → 应用与权限 → 权限管理 → 自启动` → 打开本应用。
4. `设置 → 电池 → 省电管理`：确认没开「超级省电」。
5. 最近任务 → 长按卡片 → 锁图标。

影响
- OriginOS 5 起内存策略更严，不加白名单时后台进程被回收概率明显上升，**后台更新容易做到一半被清**；
- 「智能控制后台耗电」看着像放行，实际锁屏一段时间后会切断唤醒 → 闹钟会被合并，所以选「允许后台高耗电」。

---

## 5. 华为 / 荣耀（HarmonyOS 4.x、MagicOS）

主要入口
- `设置 → 应用和服务 → 应用启动管理`（老版本在 `设置 → 电池`）
- 手机管家 → 应用启动管理

步骤
1. `设置 → 通知和状态栏 → 北邮课程表`：允许通知。
2. `设置 → 应用和服务 → 应用启动管理` → 找到本应用 → **关闭「自动管理」**。
3. 弹窗里勾上：**允许自启动**、**允许后台活动**（关联启动不必勾）。
4. 最近任务 → 下拉应用卡片加锁。

影响
- 默认「自动管理」会按使用频率收紧，冷门时段闹钟被合并；
- 只有关掉「自动管理」后，那三个开关才真正生效（这是最容易漏的一步）。

注意
- **HarmonyOS NEXT（5.x，纯血鸿蒙）** 不兼容 Android 应用：APK 装不上，只能用网页版（看课表 + 手动导入，提醒不可靠）。

---

## 6. 三星（One UI）

主要入口
- `设置 → 常规管理 → 电池 → 后台使用限制`
- `设置 → 应用程序 → 北邮课程表 → 电池`

步骤
1. `设置 → 通知 → 高级设置 → 北邮课程表`：允许通知。
2. `设置 → 常规管理 → 电池 → 后台使用限制` → 把本应用从「休眠 / 深度休眠」移到 **永不休眠**。
3. `设置 → 应用程序 → 北邮课程表 → 电池` → 选「**不受限制**」。
4. `设置 → 电池 → 更多电池设置` → 关闭对本应用的「自适应电池」优化。

影响
- 「深度休眠」= 完全不后台运行，通知只在你打开应用时补发 → **不设这条，提醒基本等于没有**；
- 设为「不受限制」后，闹钟与短时后台都正常，发热/耗电影响可忽略（本应用不常驻）。

---

## 7. 其它 Android（原生 / Pixel / 摩托 / 索尼等）

1. `设置 → 应用 → 北邮课程表 → 通知`：允许通知。
2. `设置 → 应用 → 北邮课程表 → 电池` → 「**不受限制**」（Unrestricted）。
3. `设置 → 电池 → 电池优化 → 本应用 → 不优化`。
4. 系统弹「此应用在后台耗电」时选「允许继续」，不要选「限制」。

原生的限制较轻，做完这两步闹钟通常就很准，不需要额外折腾。

## 8. 影响对照表（设与不设差在哪）

| 设置项 | 不设的后果 | 设了之后 |
|---|---|---|
| 通知权限 / 通知渠道 | 闹钟到点了但没有通知，看起来"完全没提醒" | 准点弹出通知，锁屏可见 |
| 电池优化白名单 | Doze 把唤醒窗口拉长，闹钟晚几分钟~十几分钟 | 准点（误差 <1 分钟） |
| 自启动 | 手机重启后系统不再拉起本应用，排好的闹钟在重启后**全部失效**（本应用有开机重排，但进程要能起来） | 重启后自动重排，照常提醒 |
| 后台活动 | 后台更新课表跑到一半被清 → 页面停在中间，数据没变 | 后台更新能跑完，回来就能看差异 |
| 关联启动 | 无影响（本应用不靠别人拉起） | 开了只会多耗电，**不建议开** |

一句话：**前 4 项决定"提醒准不准"，第 5 项（关联启动）不需要动。**

## 8.5 桌面小组件：这些系统都能加吗

**能。** 本应用的小组件是标准 Android App Widget（`AppWidgetProvider`），只要是支持桌面小部件的启动器就能加——MIUI/HyperOS、ColorOS、OriginOS、HarmonyOS 4.x（兼容 Android 应用的版本）、One UI 都支持。

| 系统 | 添加路径 |
|---|---|
| 小米 / 红米 / POCO | 长按桌面空白处 → **添加小部件**（旧版「添加工具」）→ 找到「北邮课程表」→ 拖到桌面 |
| OPPO / 一加 / realme | 长按桌面空白处 → **卡片**（部分版本叫「小组件」）→ 全部应用 → 北邮课程表 |
| vivo / iQOO | 长按桌面空白处 → **原子组件** → 找到「北邮课程表」（OriginOS 同时兼容标准 Android 小组件） |
| 华为 / 荣耀（鸿蒙 4.x、MagicOS） | 长按桌面空白处 → **窗口小工具** → 北邮课程表（注意：「服务卡片」是鸿蒙原生卡片，不是这个） |
| 三星 | 长按桌面空白处 → **小组件** → 北邮课程表 |
| 原生 / Pixel 等 | 长按桌面空白处 → **小组件（Widgets）** → 北邮课程表 |

**不能加的情况**（没有对应实现，不是设置问题）
- **iOS**：装不了 APK，网页版也没有桌面小组件。
- **纯血鸿蒙（HarmonyOS NEXT 5.x）**：不兼容 Android 组件，只能用网页版。

小组件的三个硬限制
1. **尺寸**：默认 4×3（250×184dp），双向可缩放；高度变小会自动少显示几行课。
2. **刷新**：App 内改课 / 确认补班日 → 立刻推一次；**没打开 App 时，系统最快每 30 分钟给一次刷新**（Android 硬限制）。
3. **不依赖保活设置**：小组件由启动器负责绘制，`updatePeriodMillis` 到点由系统唤醒，**不需要**上面那套自启动/后台活动也能刷新；但保活设置能让"App 内改动 → 立刻刷新"更及时。

## 9. 怎么验证有没有生效

1. **权限自检**：提醒页点「发一条测试通知」，立刻能收到 → 通知渠道正常。
2. **白名单自检**：`提醒 → 后台保活设置` 页顶部会显示「电池优化：已豁免 / 未豁免」（App 内直接读系统状态）。
3. **存活自检**：切到后台、锁屏 10 分钟再回来，课表与提醒页状态都还在，说明没被清。
4. **终局判据**：明天第一节 **提前量（默认 15 分钟）** 前是否准时响——前一天晚上别手动清理后台。

排查
- 亮屏时准、锁屏时不准 → **后台活动 / 自启动**没放开。
- 通知渠道给了但完全没动静 → 通知总开关或「电池优化」没给。
- 只在重启后失效 → **自启动**没给。

---

## 10. 不建议做的事

- ❌ 关闭系统级省电 / 关「优化」全局开关：影响整机续航，对本应用的收益远小于代价。
- ❌ 安装第三方"保活 / 冻结 / 清理"类 App：常与本应用争夺唤醒，反而更容易被系统判定异常。
- ❌ 打开「关联启动」全家桶：本应用不需要被其它应用拉起。
- ❌ 打开开发者选项里的「不保留活动」：会让任何应用切走即销毁。
